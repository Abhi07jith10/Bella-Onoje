Bella Onojie - Food Delivery Landing Page

A modern and responsive food delivery landing page built using HTML, CSS, and JavaScript. This project showcases a visually appealing user interface for a food delivery application, featuring smooth animations, mobile responsiveness, and a clean user experience.

🚀 Features
Responsive design for mobile, tablet, and desktop devices
Modern and attractive UI/UX
Interactive navigation menu
Smooth scroll animations using ScrollReveal.js
Call-to-action sections for app downloads
Social media integration in the footer

🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
ScrollReveal.js
Remix Icons
